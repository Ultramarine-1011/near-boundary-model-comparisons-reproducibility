The implementation includes exact ternary-population enumerations, conditional-factor checks, prefix-measurability checks, and edge-case tests. Experiment scripts rebuild processed matrices and regenerate simulations, real-data replays, tables, and figures. Per-run records, per-cell summaries, dataset counts, exclusions, seeds, and SHA-256 digests are retained in the experiment archive.

A separate standard-library audit checks 1,118,200 recorded outcomes for completeness and internal consistency, and recomputes selected headline figures from raw records. An independent target audit recomputes all 563,200 real-study means and labels from integer score totals and rational margins. A clean rebuild from source archives reproduced seven matrices and all 1,051,600 baseline replay records exactly in the recorded environment, and passed 15 unit tests; the two supplementary reporting checks also matched. The release contains a further 66,600 boundary-focused replays, verified by a second execution with an identical SHA-256 digest, and three additional tests, bringing the passing total to 18. Those tests exhaustively check small-population edit alternatives, the sufficient-bound algebra, and an exact rare-event diagnostic. The boundary-focused replay set was not separately rebuilt in a second directory. These checks do not replace statistical proofs or establish external validity. No model API calls are required. Complete proofs appear in Appendix~\ref{app:a}.

Experiments were replayed locally on CPU under Windows with Python 3.12.14, NumPy 2.3.5, pandas 3.0.1, SciPy 1.18.1 and Matplotlib 3.11.1. No GPU or paid model API was required. Hardware-specific runtimes are not used as cost claims.
